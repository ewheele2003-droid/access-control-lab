# Access Control Management Lab User access control procedures for SealGames Studios. Includes access control policy, request tracking, and NIST 800-171 aligned procedures demonstrating role-based approval workflows and compliance documentation. ## Files - Access_Control_Policy.md - Complete access control procedures and timelines - Access_Request_Tracker.csv - Template for tracking user access requests - Access_Request_Form_Ray_Smith.md - Sample request walkthrough from submission to implementation ## Workflow 1. Employee submits access request with business justification 2. Manager (Tech Lead/QA Manager) reviews and approves within 2 business days 3. System Administrator implements access within 24 hours 4. Access logged in audit trail for compliance ## NIST Controls AC-2, AC-3, AC-2(1), AU-2 Status: Complete
